## S9_R1_AT1_HTML

### Atividade de Apropriação

- *required* -> Torna um campo obrigatório
- *minlength* -> Define um tamanho mínimo para o texto inserido
- *maxlength* -> Define um tamanho máximo para o texto inserido
- *min* -> Define um valor mínimo para o valor inserido
- *max* -> Define um valor máximo para o valor inserido
- *pattern* -> Define uma regra de preenchimento
- *placeholder* -> Cria um `texto fantasma` para servir de sugestão para inserção
